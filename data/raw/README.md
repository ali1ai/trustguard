# Raw datasets (not committed)

Download the UCI SMS Spam Collection with `python scripts/download_sms_dataset.py`.
It is distributed under CC BY 4.0, so preserve attribution when redistributing derived
materials. Raw dataset files are excluded from Git.

The toxicity baseline streams a bounded sample from the Civil Comments dataset on
Hugging Face. Its dataset card identifies it as CC0 1.0. Read the source card and
its limitations before use: https://huggingface.co/datasets/google/civil_comments
