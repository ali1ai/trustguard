# TrustGuard Architecture

## Runtime path

1. Validate request payload and length in FastAPI.
2. Generate cheap, explainable local spam/threat/harassment signals.
3. Load trained spam and/or toxicity artifacts if they exist.
4. Optionally call provider moderation and contextual analysis when explicitly enabled.
5. Invoke the independent auditor only for ambiguous/low-confidence/conflicting cases.
6. Map signals to a recommendation through deterministic policy code. LLMs do not execute actions.
7. Return category scores, separately displayed trained-model outputs, data sources, warnings, policy version, and explanation.
8. Persist nothing by default. Review/audit storage must be enabled explicitly and needs a private, secured deployment.

## Trained text models

Each model artifact contains a format version, task name, sklearn estimator, decision threshold, and training metadata. Runtime validates the artifact version/task and degrades to heuristics if loading fails. Only load artifacts generated by your own trusted training process because joblib/pickle deserialization is unsafe for untrusted files.

The trainer normalizes message casing/whitespace, collapses same-label duplicates, and excludes normalized text groups with contradictory labels before splitting. It compares (a) word TF-IDF + Multinomial Naive Bayes and (b) word+character TF-IDF + Logistic Regression. It fits candidates on the training partition, selects threshold/model using validation data, then publishes held-out metrics. `scores` is a max-over-sources signal map, not a calibrated probability or a learned ensemble; `model_scores` keeps local model outputs separate, and `model_thresholds` exposes each validation-selected decision threshold.

## Public deployment boundary

The same FastAPI process serves the static browser UI and JSON API. Provider calls are off by default. Content storage, audit-event storage and reviewer endpoints are off by default. A production version would still need authentication, rate limiting, abuse monitoring, a privacy/retention policy, access controls, and operational metrics.
